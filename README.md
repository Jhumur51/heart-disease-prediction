# Heart Disease Prediction

This project predicts the presence of heart disease using machine learning.

## Dataset

The project uses the UCI Heart Disease dataset.

## Machine Learning Model

- Random Forest Classifier
- Train-Test Split
- Classification Report
- Confusion Matrix

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Workflow

1. Load the dataset
2. Explore the data
3. Check missing values
4. Preprocess the data
5. Split data into training and testing sets
6. Train the Random Forest model
7. Evaluate the model
8. Display the confusion matrix

## Files

- `heart_disease.ipynb` - Main Jupyter Notebook
- `heart_disease_uci.csv` - Dataset
